# VolumePPT

스마트폰의 **볼륨 버튼**을 무선 프레젠테이션 리모컨으로 바꿔 줍니다.

| 휴대폰 버튼 | PPT 동작 |
|---|---|
| 볼륨 ▲ (업) | 다음 슬라이드 |
| 볼륨 ▼ (다운) | 이전 슬라이드 |

안드로이드와 아이폰 모두 지원하고, 앱을 설치하지 않아도 되는 웹 리모컨도 들어 있습니다.
PowerPoint 외에 Keynote, Google Slides, PDF 뷰어처럼 방향키로 넘어가는 프로그램이면 모두 동작합니다.

```
[휴대폰 앱] --(같은 Wi-Fi, HTTP)--> [PC 서버 server.py] --(→ / ← 키 입력)--> [PowerPoint]
```

## 구성

| 폴더 | 내용 |
|---|---|
| `pc/` | PC(Windows / macOS)에서 실행하는 서버. 휴대폰 신호를 받아 방향키를 누릅니다. |
| `android/` | 안드로이드 앱 (Android 5.0 이상) |
| `ios/` | 아이폰 앱 (iOS 15 이상, SwiftUI) |

---

## 1. PC 서버 실행

Python 3.8 이상이 필요합니다.

- **Windows**: `pc/start_windows.bat` 더블클릭
- **macOS**: `pc/start_mac.command` 더블클릭
  - 처음 실행할 때 *시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용* 에서 터미널(또는 Python)을 허용해야 키 입력이 동작합니다.
- 직접 실행:
  ```bash
  cd pc
  pip install -r requirements.txt
  python server.py
  ```

실행하면 휴대폰에 입력할 주소가 표시됩니다.

```
 휴대폰 앱에 아래 주소를 입력하세요 (같은 Wi-Fi):
   192.168.0.10:8765
```

옵션:

| 옵션 | 설명 |
|---|---|
| `--port 9000` | 포트 변경 (기본 8765) |
| `--token 1234` | 비밀번호 설정. 같은 Wi-Fi 의 다른 사람이 슬라이드를 넘기지 못하게 합니다. |
| `--dry-run` | 키를 누르지 않고 로그만 출력 (테스트용) |

> Windows 방화벽 알림이 뜨면 **개인 네트워크 허용**을 눌러 주세요.

## 2. 휴대폰 앱

### 안드로이드
- **APK 받기**: 이 저장소의 GitHub **Actions → Build Android APK** 실행 결과에서 `VolumePPT-apk` 를 내려받아 설치합니다. (출처를 알 수 없는 앱 설치 허용 필요)
- 또는 Android Studio 로 `android/` 폴더를 열어 실행합니다.

### 아이폰
Mac 과 Xcode 가 필요합니다.
```bash
brew install xcodegen
cd ios
xcodegen generate
open VolumePPT.xcodeproj
```
Xcode 에서 *Signing & Capabilities* 에 본인 Apple ID 팀을 선택하고 아이폰에 실행합니다.
처음 실행 시 **로컬 네트워크 접근 허용**을 눌러 주세요.

### 앱 없이 (모든 휴대폰)
휴대폰 브라우저에서 `http://192.168.0.10:8765` 를 열면 화면 버튼 리모컨이 나옵니다.
(웹 브라우저는 보안상 볼륨 버튼을 받을 수 없어서 화면 버튼만 확실히 동작합니다.)

## 3. 사용법

1. PC 에서 서버를 켜고 PowerPoint 슬라이드 쇼를 시작합니다 (슬라이드 쇼 창이 활성 창이어야 함).
2. 휴대폰 앱에 PC 주소를 입력하고 **연결 테스트** → `✅ 연결됨` 확인.
3. 볼륨 ▲ / ▼ 로 슬라이드를 넘깁니다. 화면의 큰 버튼도 사용할 수 있습니다.

## 알아 두기

- 앱이 **화면에 떠 있을 때만** 볼륨 버튼이 리모컨으로 동작합니다. 앱이 켜져 있는 동안 화면이 꺼지지 않게 해 두었습니다.
- 앱이 켜져 있는 동안 볼륨 버튼은 휴대폰 음량을 바꾸지 않습니다. (아이폰은 내부적으로 음량을 중간값으로 되돌리는 방식을 씁니다.)
- 휴대폰과 PC 가 **같은 Wi-Fi** 에 있어야 합니다. 공용/회사 Wi-Fi 에서 기기 간 통신이 막혀 있다면 휴대폰 핫스팟에 PC 를 연결해서 쓰세요.
- 블루투스 프레젠터나 셔터 리모컨(Page Up/Down, 미디어 키)을 휴대폰에 연결해도 같이 동작합니다.
